# Dark Angels battle companion — 11th edition audit

Checked 2026-11-25 against Wahapedia’s listed Space Marines/Dark Angels app 2.8.1 (October 2026) and live core rules/FAQ. Audited battle.html, not the separate 252-entry dictionary. This is a review, not a rules engine or edited project.

Match = main summary agrees; Expand = important omitted condition or useful detail; Correct = change needed to avoid a wrong rule/reference; Conditional = mission-dependent; Ambiguous = unresolved source wording. The list does not certify all possible interactions.

## Implementation issues

- Attached unit is currently rendered in two groups. Shared action checks should be keyed by actual attached unit/source, not displayed roster row. Azrael’s Watcher already has a shared once-use key; keep it. Only Azrael buffs are copied into bodyguard view; bodyguard defensive and offensive buffs should also be visible for Azrael.
- Round-start CP should not be counted twice across player-turn views, and needs a Warlord alive/destroyed toggle.
- Track used stratagem names per phase and actual target units per phase (15.01); checks currently do not enforce either limit.
- Hide or clearly mark unavailable options for units off-board, destroyed, engaged, already battle-shocked, etc. The app is a manual reference, not an automatic legality engine.
- Add Start of Turn and round-three reserves deadline.
- Update embedded glossary Lethal Hits to state the choice; add snap-shooting noncritical hits and Precision + Devastating Wounds clarification.
- Replace generic source links with section anchors when verified; use combined datasheets for Eradicators rather than older generic listing.

## Limits

Wahapedia is a third-party reference; official app and tournament rulings take precedence. No mission deck or live official app was available for this review. Existing HTML and GitHub ZIP are unchanged.
